## 6. Применённые техники тест-дизайна

- **Эквивалентное разбиение**: валидные/невалидные учётные данные, значения `Update Interval`, комбинации `resultCode`.
- **Анализ граничных значений**: `End Date = Start Date`, `End Date = Start Date + 1 сек`, границы зума 100% / 300%, недостаток записей для 10/100/1000.
- **Таблицы принятия решений**: комбинации заполненности `Phone` / `Password` и состояние кнопки «Sign In»; комбинации чекбоксов `resultCode`.
- **Переходы состояний**: авторизация → окно периода → главное окно; переключение `InRealTime` ↔ `ByPeriod`.
- **Риск-ориентированный подход**: приоритет High для авторизации, доступа к данным, расчётов и обработки потери БД.
